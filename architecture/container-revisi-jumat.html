War Tiket Konser — Container (Revisi Jumat)

Disederhanakan: Web+Admin digabung · Backend monolit (event+ticket) · Tanpa payment/notif eksternal dulu

Target Jumat: Web menampilkan gambar/poster tiket, bisa memilih kursi, informasi tiket, dan jumlah/sisa kursi (live dari backend).

Yang dikerjakan sekarang

  • Clients: Web (Admin digabung / tidak terpisah dulu)
  • Edge: API Gateway sederhana = Express static + /api/* (Load Balancer belakangan)
  • Services: Backend monolit = event-service + ticket-service digabung
  • Data: PostgreSQL + Redis (kuota atomik + denah sold)
  • Ditunda: payment-service, notification-service, Email/SMS, Payment Gateway, Message Queue terpisah

Cara jalankan demo Jumat

  1. Pastikan Postgres + Redis jalan
  2. npm start di root repo
  3. Buka http://localhost:3000/
  4. Pilih kursi hijau → Pesan tiket → sisa kursi berkurang
